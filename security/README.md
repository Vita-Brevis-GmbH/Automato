# Security

Zentrale Sicherheitsbausteine der Plattform:
- Secrets-Management (Start: Ansible Vault → später HashiCorp Vault)
- AuthN/AuthZ-Module (RBAC) für Orchestrator & Web UI
- Audit-Log-Komponente
- Zertifikats-/mTLS-Verwaltung für interne Kommunikation

Siehe SECURITY.md (Projekt-Root) für das Gesamtkonzept.
